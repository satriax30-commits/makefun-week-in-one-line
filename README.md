A deterministic Node 22 program that writes one line summing up a week of 122 make.fun bounty entries — zero wins, one line left, and the punchline is the 100-character limit itself — to `/output/entry.txt` for make.fun's "Your Week in One Line" bounty.

## Run it

```sh
node main.ts
```
